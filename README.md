# Secure Parcel Tracking System

A university dissertation project developed as a secure full-stack parcel tracking web application using Laravel, Docker and MySQL.

## Overview

The system allows different user roles to access parcel tracking functionality based on their permissions. It includes authentication, role-based access control, parcel event logging and an audit trail to support accountability.

## Key Features

- User authentication
- Role-based access for admin, courier and customer users
- Parcel tracking functionality
- Delivery event logging
- Audit trail for delivery updates
- Protection against unauthorised access to restricted routes
- STRIDE-based threat modelling used during design

## Technologies Used

- Laravel / PHP
- MySQL
- Docker
- Git
- Microsoft Threat Modeling Tool
- HTML / Blade templates

## Security Note

This project is shared for portfolio and demonstration purposes only. No real user data, production credentials or live deployment secrets are included. The `.env` file is excluded from the repository and only a safe `.env.example` file is provided.

## Purpose

This project was developed as part of a university dissertation to explore secure web application design and threat modelling in a parcel tracking context.
